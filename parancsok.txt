SZERVER VÁLASZOK:
4 A kérés befejeződött, a válasz megérkezett.

200 OK
→ sikeres kérés

201 Created
→ sikeresen létrejött valami

400 Bad Request
→ hibás kérés

401 Unauthorized
→ nincs bejelentkezve / nincs jogosultság

403 Forbidden
→ tiltott hozzáférés

404 Not Found
→ nem található az oldal vagy API

500 Internal Server Error
→ szerverhiba

502 Bad Gateway
→ hibás szerver kapcsolat

503 Service Unavailable
→ a szerver nem elérhető
